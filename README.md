# ARISE - Digital Marketing Website

A complete, professional, modern single-page website for **ARISE** — a premium digital marketing brand.

## 🌐 Live Site

**[https://abidurrahman1515.github.io](https://abidurrahman1515.github.io)**

## 📋 Description

ARISE is a cutting-edge digital marketing agency website built with pure HTML, CSS, and vanilla JavaScript. It showcases the brand's services, portfolio, testimonials, and provides a contact form — all in a sleek, dark, gold-accented design.

## ✨ Features

- **Preloader** with animated ARISE logo
- **Sticky navbar** with scroll-based transparency, active link highlighting, and mobile hamburger menu
- **Hero section** with particle canvas animation, floating gradient orbs, and animated headline
- **About section** with count-up stats (IntersectionObserver)
- **Services section** — 6 service cards with hover glow effects
- **Portfolio section** — 6 project cards with CSS gradient backgrounds and hover overlays
- **Testimonials carousel** — auto-scrolling with swipe/touch support
- **Contact section** — client-side validated form + social links
- **Footer** with quick links
- **Back-to-top** button
- Fully **responsive** (mobile, tablet, desktop)
- **Smooth scroll** and scroll-reveal animations

## 🛠 Tech Stack

- HTML5
- CSS3 (custom properties, flexbox, grid, animations)
- Vanilla JavaScript (ES5-compatible)
- Google Fonts (Montserrat + Inter)
